# monthly-communication-writer

根据历史月度沟通、当月飞书工作记录和本地实际产出，填写并核验“1 on 1 月度沟通”Excel 的 Codex Skill。

> 本 README 是给同事看的快速导览；AI 执行时以 [`SKILL.md`](SKILL.md) 为准。

## 能做什么

- 学习历史月度沟通的栏目、语气、篇幅和表格样式。
- 汇总当月已完成、推进中、测试中和日常工作的真实证据。
- 撰写工作产出、主动推进、成长收获、AI agent 应用、困难和支持诉求等内容。
- 在历史工作簿中新增当月记录，同时保留全部历史内容和原有格式。
- 对新增行进行数据核验和视觉检查，避免错列、截字或格式变化。

## 什么时候使用

同事提出以下需求时使用：

- “参考上个月，写一下本月 1 on 1 月度沟通。”
- “读取本月飞书工作记录，填写月度沟通表。”
- “补充这个月的 AI agent 应用和主动推进事项。”
- “解释月度沟通里这句话具体来自哪条工作记录。”

## 需要提供什么

- 要填写的年份和月份；没有明确说明时，AI 会结合当前日期和文件判断。
- 历史月度沟通 Excel，或允许读取约定的工作记录目录。
- 当月飞书工作记录的访问权限。
- 对未记录在固定资料中的重要成果，补充文件、链接或说明。

## 会产出什么

- 一份延续历史格式和写作风格的当月月度沟通 Excel。
- 工作产出、主动推进、成长、AI 应用、困难和支持诉求等栏目的完整内容。
- 对来源冲突、含义模糊或缺少证据的事项给出确认提示。
- 用户追问时，可说明关键表述来自哪张表、哪个日期或哪个文件。

## 工作流程

1. 确认月份并找到最新历史工作簿。
2. 学习最近数月的栏目结构、语气和格式。
3. 读取当月飞书记录及本地工作产出。
4. 区分完成、推进、测试和计划，形成可追溯文案。
5. 在表头下新增当月行，保存为新文件。
6. 检查内容、列映射、历史数据和视觉样式。

## 安装

```bash
git clone https://github.com/fanlili321/monthly-communication-writer.git \
  ~/.codex/skills/monthly-communication-writer
```

安装后可这样触发：

```text
使用 $monthly-communication-writer，参考历史文件填写 2026 年 9 月的 1 on 1 月度沟通。
```

## 依赖与权限

- Codex Skills 运行环境。
- 飞书工作记录表的读取权限。
- 可读取历史 Excel 和本地工作产出的文件权限。
- 需要可用的表格处理能力完成 Excel 读写与版式核验。

## 使用边界

- 不把“测试中”写成“已落地”，不把一次修改夸大为完整项目。
- 不编造工具名、成果数量、效率比例、困难或支持诉求。
- 飞书与本地资料冲突时采用保守表述，并提示用户确认。
- 不覆盖上月文件，默认只保留一份正式的新月度成果。

详细字段、写作规则、固定路径和来源追溯要求见 [`SKILL.md`](SKILL.md)。
